## Featured Project 01

### Machine Learning-Based AI Feedback Acceptance Predictor

**Educational Purpose:**  
To develop a prototype for predicting how English learners may respond to AI-generated feedback.

**Technologies:**
- Python
- Pandas and NumPy
- Scikit-learn
- Logistic Regression
- Random Forest
- Streamlit
- Matplotlib

**Implemented Features:**
- Synthetic dataset generation (300 records)
- Machine learning model training and evaluation
- Classification into Accept, Edit, and Reject
- Confusion matrix and feature importance visualization
- Interactive Streamlit web application
- GitHub integration and cloud deployment

**Research Relevance:**  
This project provides a technical foundation for future research on AI trust, appropriate reliance, and trust calibration in educational contexts.

**Data Note:**  
The current prototype uses randomly generated synthetic data for technical demonstration. It does not represent validated predictions of actual learners' behavior.
